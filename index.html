カードの「アプリを見る」で新しいタブに開きます。すべて Vercel で静的配信。

絞り込みは 8 つの軸 —— Track(どんな能力か)・分野(何を対象にしたか)・ 手法・表示と体験・言語・実装・出典・シリーズ。 同じ軸の中は OR、違う軸どうしは AND で掛け合わせられます (例: 文学・民俗・言語 × 自然言語処理 × 青空文庫)。チップの数字は いま押したら何件になるかで、0 件のチップは押せません。 絞り込んだ状態は URL にそのまま残るので、共有できます。

カードの言語・実装・バッジは実測値です。各リポジトリを走査して数え、 111 プロジェクトで共通のスキャフォールドは除いてあります。ライブラリの印は 🚚 出荷 = ブラウザで動く / 🏭 生成 = 手元で重みや JSON を作った / ⚖️ 照合 = オラクル専用。バッジの判定条件は taxonomy.json に書いてあります。

初回デプロイ日・最終更新日は Vercel のプロジェクト作成日と各リポジトリの 最終コミット日(JST)。ソースが GitHub にないアプリには GitHub のボタンを出しません。
